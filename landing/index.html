Cómo funciona

Tres piezas, nada más. Tu IA pide, el protocolo MCP lo lleva por internet y el servidor lo ejecuta.

Tu IAClaude, Cursor, VS Code…
MCPPor internet, con tu URL y tu credencial
MCP-ASIREl servidor, ya en marcha

Tu IA es el cliente: la app donde escribes.

MCP es el protocolo, como un USB-C: un mismo enchufe para conectar cualquier herramienta a cualquier IA.

MCP-ASIR es este proyecto: un servidor que ya está online esperando. No te lo descargas, solo te conectas con tu URL y tu credencial.

Guía rápida

Conéctalo con Google

Necesitas una aplicación compatible con MCP remoto y acceso aprobado previamente. Para solicitarlo, escribe a me@raulcn.com indicando tu cuenta de Google.

https://mcp.bztracker.xyz/mcp
Ejemplo · Claude

Conéctalo en 3 pasos

  1. Añade el conector

    En Claude, abre Personalizar → Conectores y elige Añadir conector personalizado. Llámalo MCP-ASIR y pega la URL de arriba.

  2. Entra con Google

    Pulsa Conectar, elige tu cuenta y autoriza la conexión. Iniciar sesión no concede acceso automáticamente: espera a que se apruebe tu solicitud y vuelve a conectar. Si te pide cómo registrar el cliente, elige Register automatically.

  3. Pregunta por tus apuntes

    Activa MCP-ASIR en la conversación y pide a Claude que busque en los materiales de tu asignatura.

Por ejemplo: «Busca en ASO cómo cambiar la prioridad de un proceso y dime de qué apuntes sale».

La disponibilidad de conectores personalizados depende del cliente y de su plan. En otros clientes compatibles, busca la opción de añadir un servidor MCP remoto.

¿Tienes un token personal?

También puedes usar un token facilitado por Raúl en clientes que admitan credenciales fijas. Trátalo como una contraseña y no lo publiques.

{
  "mcpServers": {
    "mcp-asir": {
      "url": "https://mcp.bztracker.xyz/mcp",
      "headers": {
        "Authorization": "Bearer TU_CREDENCIAL"
      }
    }
  }
}

Sustituye el marcador por tu token. Si tu cliente dispone de un almacén de secretos, úsalo; evita pegarlo en comandos del historial.
